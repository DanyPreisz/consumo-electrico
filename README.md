# Predicción de Consumo Eléctrico Horario

Proyecto de regresión / series de tiempo listo para Google Colab. Incluye EDA, lags, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/consumo-electrico/blob/main/consumo_electrico_colab.ipynb)

## Contenido

- Serie de consumo horario simulada (ciclo diario + semanal + ruido)
- Features: lags, media móvil, temperatura, fin de semana
- EDA (plot de serie, scatter, boxplot)
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Datos: simulados

Rango esperado (ejemplo): R² > 0.75
